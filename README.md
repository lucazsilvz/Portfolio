## 📌 Sobre o Projeto

Este é o repositório do meu **portfólio pessoal**, desenvolvido para centralizar e apresentar minha trajetória na área de Tecnologia, minhas competências técnicas e os projetos práticos que venho construindo.

Sou estudante de **Análise e Desenvolvimento de Sistemas** e atuo como **Jovem Aprendiz em Suporte de TI**, combinando vivência prática no suporte e infraestrutura com dedicação constante aos estudos em desenvolvimento web, lógica de programação e engenharia de software.

---

## ✨ Seções do Site

- **Hero / Início:** Apresentação dinâmica com destaque de perfil, resumo e atalhos rápidos.
- **Sobre Mim:** Detalhamento da minha jornada acadêmica, experiência profissional e objetivos na área tech.
- **Tecnologias:** Visão visual e categorizada das tecnologias com as quais trabalho e estou aprofundando.
- **Projetos:** Vitrine interativa com descrição, stack utilizada e links diretos para repositórios.
- **Contato:** Canais diretos para networking e oportunidades (LinkedIn, GitHub e E-mail).

## 💻 Como Visualizar Localmente

Para clonar e testar o projeto no seu computador:

```bash
# 1. Clone o repositório
git clone https://github.com/lucazsilvz/Portf-lio.git

# 2. Acesse a pasta do projeto
cd Portf-lio

# 3. Abra o arquivo index.html no seu navegador
# No Windows via terminal:
start index.html
```
